# Contributing

Thanks for your interest in improving `TextCombinatorWinForms`.

## How to contribute

1. Fork the repository
2. Create a feature branch
3. Make focused changes with clear commit messages
4. Open a pull request with a short explanation and screenshots (if UI changed)

## Local setup

```bash
dotnet restore
dotnet build
dotnet run
```

## Style notes

- Keep UI labels simple and clear
- Preserve category order behavior for combination generation
- Keep output format user-friendly (line-based text with blank line separation)
